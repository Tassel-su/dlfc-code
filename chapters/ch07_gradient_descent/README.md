## 这一章在讲什么

训练神经网络 = 最小化误差函数。本章是"优化引擎"手册：误差曲面的几何
（二次近似、条件数）、批量/随机/小批量梯度下降、动量、学习率调度、
RMSProp/Adam，以及数据/批/层归一化 —— 全是训练实战的核心技巧。

## 关键推导（中文）

### 推导 1：为什么普通 GD 受条件数限制

E ≈ ½(w-w*)ᵀH(w-w*)，H 特征分解为 λ_i u_i u_iᵀ。
梯度下降沿特征方向的收敛速度为 (1-ηλ_i)^k，要求 η < 2/λ_max。
因此 λ_max 大 -> 步长必须小 -> 最慢方向 (λ_min) 收敛极慢，
速度差距 = 条件数 λ_max/λ_min。动量通过累积速度绕过这个限制。

### 推导 2：动量为什么快

动量 v ← μv - η∇E 是一个带阻尼的"质量-弹簧"系统：
沿平坦方向（梯度小）速度不断累积，快速穿越；
沿陡峭方向（梯度大）来回振荡被 μ 阻尼。有效学习率从 η
提升到 η/(1-μ) 的量级，却不牺牲稳定性。

### 推导 3：Adam 的两步归一化

- 一阶矩 m = βm + (1-β)g：梯度的移动平均（动量方向）
- 二阶矩 s = β₂s + (1-β₂)g²：梯度平方的移动平均（每维尺度）
- 更新 w ← w - η·m̂/√ŝ，其中 m̂,ŝ 是去偏估计
效果：每维步长 = η / (该维梯度均方根)，大梯度维自动缩小步长，
小梯度维自动放大 —— 等价于把病态问题的每维坐标轴"拉圆"。

## 自测题（答案在下方）

1. 条件数大为什么难优化？动量怎么绕过它？
2. SGD 相比批量 GD 的优缺点？
3. 为什么固定学习率的 SGD 会停在"噪声地板"？
4. Adam 的自适应步长是怎么实现的？
5. 数据标准化为什么能让学习率变大？

<details>
<summary>答案</summary>

1. 条件数 = λ_max/λ_min。步长被 λ_max 限制（η<2/λ_max），
   最慢方向（λ_min）收敛慢，差距达 λ_max/λ_min 倍。
   动量累积平坦方向的梯度，等效放大小方向的学习率。
2. 优点：单步便宜、天然在线、能逃离局部极小（噪声帮助）；
   缺点：梯度有噪声，收敛不单调，需要调学习率/调度。
3. 固定 η 时，随机梯度在最优解附近的波动（噪声地板）与 η 成正比，
   误差无法低于 O(η·噪声²)。衰减学习率把 η 减小，地板随之降低。
4. 用梯度平方的移动平均估计每维尺度，步长 = η/√s：
   大梯度维 s 大 → 步长小；小梯度维 s 小 → 步长大。
5. 标准化把各维尺度拉到同一量级，条件数回到 O(1)，
   最大特征值不再巨大 → 允许大得多的 η 而不会发散。
</details>
