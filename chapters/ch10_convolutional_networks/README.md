从全连接走向卷积：图像是空间相关的，卷积用**共享权重 + 局部感受野**
把这种先验编码进架构（平移等变）。本章从零实现卷积（im2col）、池化、
完整 CNN 的训练（纯 numpy 反向传播），以及可视化（滤波器/显著性/对抗）、
检测（IoU/NMS）、分割（上采样）、风格迁移（Gram 矩阵）。

## 关键推导（中文）

### 推导 1：卷积的前向（im2col）

每个输出位置 y 对应输入上 kh×kw 的感受野。im2col 把每个感受野
拉成一行（列索引 = 通道×核位置），于是：
    输出 = W 展平 (F, C·kh·kw) @ cols (N, C·kh·kw, H'·W')
反向时：dW = dout @ colsᵀ，dcols = Wᵀ @ dout，再 col2im 散回原图。

### 推导 2：池化的反向

最大池化只保留每个 2x2 块的最大值位置。反向时把梯度
只加回到前向选中的那个位置（其余位置梯度为 0）—— 用 argmax 索引即可。

### 推导 3：FGSM 对抗攻击

若模型对输入 x 的梯度为 ∇_x L，则 x_adv = x + ε·sign(∇_x L) 使损失增大
（一阶近似）。人眼几乎看不出 ε=0.3 的扰动，但预测可能改变 ——
证明深度网络在输入空间中存在"对抗方向"。

## 自测题（答案在下方）

1. 卷积为什么比全连接参数少？付出了什么代价？
2. 平移等变性意味着什么？
3. 最大池化的反向传播怎么做？
4. 显著性图怎么算？
5. Gram 矩阵编码了什么？

<details>
<summary>答案</summary>

1. 权重在空间位置间共享（同一滤波器滑过全图），参数量与输入尺寸无关；
   代价是放弃了"每个位置可有不同权重"的表达力（但图像本身是平移统计的）。
2. 输入平移 → 输出特征图平移（而非变化），检测同一模式无需学习位置变体。
3. 前向记录每块最大值的位置索引；反向时把梯度加到那些位置，其余为 0。
4. 对输入求损失梯度 ∂L/∂x：正值像素 = 增强它们会提高当前类别得分。
5. 特征通道间的相关统计（风格纹理）；风格迁移让生成图的 Gram 匹配风格图。
</details>
