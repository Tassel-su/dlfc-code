## 关键推导（中文）

### 推导 1：为什么 L1 产生稀疏解

L1 正则化项 λ‖w‖₁ 在原点有尖角（不可导）。最优解出现在
"误差等值线与正则化菱形相切"处——菱形角点恰好在坐标轴上，
因此解被推到坐标轴上（某些分量精确为 0）。
L2 的球是光滑的，切点一般在轴上之外 -> 只收缩不置零。

### 推导 2：残差连接为什么让深层网络可训练

残差块 h_{l+1} = tanh(W_l h_l + b_l) + h_l。
反向传播时：
    ∂E/∂h_l = ∂E/∂h_{l+1} · (1-z²)W_lᵀ + ∂E/∂h_{l+1}（恒等路径）
恒等路径的雅可比是单位矩阵：梯度可以"无损"穿过任意层数，
缓解深层网络的梯度消失。代码用深度 15 演示：无残差 0.07，有残差 1e-4。

### 推导 3：模型平均为什么降低方差

若 L 个模型独立同分布，预测方差为 σ²/L（平均后方差除以 L）。
bagging 用不同训练子集训练多个模型并平均 —— 方差降低、
偏差基本不变，总误差下降。代码演示 50 个高次拟合平均后
测试误差从 0.057 降到 0.001。

## 自测题（答案在下方）

1. 为什么"没有偏置的算法"一定不会好？
2. L1 为什么稀疏而 L2 不稀疏？
3. 双重下降现象对"模型越简单越好"的直觉有什么冲击？
4. 残差连接解决的是什么问题？
5. Dropout 为什么等价于模型平均？

<details>
<summary>答案</summary>

1. No Free Lunch：对所有可能的问题取平均，任何算法的期望表现相同；
   必须在"先验上更可能"的问题（如光滑函数）上押注 —— 这就是归纳偏置。
2. L1 的菱形在坐标轴上有尖角，最优解常落在角点（分量=0）；
   L2 的球是光滑的，解在轴上之外，只是整体收缩。
3. 它说明"容量大"不一定"过拟合"：超过插值点后，测试误差可能再次下降；
   关键不是容量大小，而是优化与隐式正则化（如 SGD 的隐式偏好）。
4. 深层网络的梯度消失/爆炸：残差的恒等路径让梯度无损穿过，
   使极深的网络（数百层）也能有效训练。
5. 训练时随机丢弃单元 = 从指数多个子网络里采样；
   测试时全网络 = 所有子网络的（近似）平均 —— 隐式集成。
</details>
