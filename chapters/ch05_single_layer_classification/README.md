## 这一章在讲什么

回归解决"预测连续值"，分类解决"预测类别"。本章覆盖分类问题的完整图景：
**判别函数**（超平面边界）、**决策论**（误分类率/期望损失/拒绝选项/ROC）、
**生成式分类器**（建模 p(x|C)，贝叶斯得到后验）、**判别式分类器**
（直接建模 p(C|x)：逻辑回归与 Softmax）。第 6 章深度网络的多分类输出
就是 Softmax —— 本章是神经网络分类的基石。

## 关键推导（中文）

### 推导 1：为什么高斯类条件密度 → logistic 后验

p(C1|x) = p(x|C1)p(C1) / [p(x|C1)p(C1) + p(x|C2)p(C2)]，取 log-odds：
    ln[p(C1|x)/p(C2|x)] = ln[p(x|C1)/p(x|C2)] + ln[p(C1)/p(C2)]
若 p(x|C_k)=N(x|μ_k,Σ)（共享协方差），代入高斯密度并展开平方项：
    = xᵀΣ⁻¹(μ1-μ2) + 常数 = wᵀx + w0
因此 p(C1|x) = σ(wᵀx + w0) —— 高斯假设自动给出 logistic 形式。
代码 5.3 直接用 MLE 的 μ1,μ2,Σ 构造 w 并画出边界。

### 推导 2：交叉熵梯度为什么是 Φᵀ(y-t)

交叉熵 E(w) = -Σ[t_n ln y_n + (1-t_n)ln(1-y_n)]，y_n = σ(wᵀφ_n)。
由链式法则：∂E/∂w = Σ (∂E/∂y_n)(∂y_n/∂a_n)(∂a_n/∂w)
其中 ∂E/∂y_n = -(t_n/y_n) + (1-t_n)/(1-y_n)，∂y_n/∂a_n = y_n(1-y_n)，
∂a_n/∂w = φ_n。三项相乘：
    = Σ [y_n - t_n] φ_n = Φᵀ(y - t)
sigmoid 的导数 y(1-y) 恰好把交叉熵的分母约掉 —— 这就是"规范链接"的魔法。
代码 5.4.3 用有限差分验证了这个梯度（误差 4e-9）。

### 推导 3：期望损失决策

给定后验 p(C_j|x)，选择类 k 的期望损失 = Σ_j L_kj p(C_j|x)。
即使 p(类2)=0.6 > p(类1)=0.4，若"漏诊类1"的代价 L_12=1.0 远大于
"误诊类2"的代价 L_21=0.1，则选类2 的期望损失 0.04 远小于选类1 的 0.60
—— 决策应最小化期望损失而非最大化后验。

## 自测题（答案在下方）

1. 为什么最小二乘不适合分类问题？
2. "生成式 vs 判别式"分类器的本质区别是什么？
3. 交叉熵梯度 ∇E = Φᵀ(y-t) 为什么这么简洁？
4. 什么时候"拒绝选项"是必要的？
5. ROC 曲线下面积 AUC=0.5 和 AUC=0.9 分别意味着什么？

<details>
<summary>答案</summary>

1. 最小二乘假设目标服从高斯分布（连续），输出是任意实数而非概率；
   且平方损失对远离边界的离群点极其敏感（边界被拉偏）。
2. 生成式建模 p(x|C_k)p(C_k)（先描述数据如何产生），再用贝叶斯求后验；
   判别式直接建模 p(C_k|x)（只关心边界）。生成式能处理缺失数据/离群点，
   判别式参数更少、更鲁棒。
3. sigmoid 导数 y(1-y) 恰好抵消交叉熵分母中的 y(1-y)；
   这是"指数族 + 规范链接"的固有性质。
4. 当误判代价很高（如医疗、自动驾驶）且后验置信不足时，
   拒绝交给人工/安全默认动作，比强行决策更优。
5. AUC=0.5：分类器与随机猜测无异（ROC 沿对角线）；
   AUC=0.9：90% 概率把正类排在负类前面，分类能力较强。
</details>
