反向传播是深度学习的引擎。本章从"梯度怎么算"出发：单层闭式解 →
一般前馈网络的链式法则 → 数值微分 → Jacobian/Hessian → **自动微分**
（前向模式 vs 反向模式）。核心成果是我们自己实现的迷你 autograd 引擎
（`autograd.py`，约 150 行），后续所有章节（Transformer/VAE/扩散）都用它。

## 关键推导（中文）

### 推导 1：单隐层 MLP 的反向传播

前向：a = W1x+b1，z = tanh(a)，y = W2z+b2，E = ½(y-t)²。
从输出开始逐层求导：
    dE/dy = y - t
    dE/dW2 = (y-t) zᵀ
    dE/da = W2ᵀ(y-t) ⊙ (1-z²)     （tanh' = 1-z²）
    dE/dW1 = dE/da xᵀ
关键在于"误差反向流动"：输出误差 (y-t) 乘以权重转置传回隐藏层，
再乘激活导数调整量级 —— 这就是"反向传播"名字的由来。

### 推导 2：反向模式为什么只需一次遍历

计算图是 DAG。反向模式从输出出发，按拓扑序的逆序传播梯度，
每个节点只处理一次（累积所有下游路径）。设 F: R^D→R^M：
- 前向模式对每个输入方向做一次遍历 → D 次
- 反向模式对每个输出做一次遍历 → M 次
深度学习的损失是标量（M=1）→ 反向模式一次遍历得到全部参数梯度。
这就是所有深度学习框架的 autograd 都基于反向模式的原因。

### 推导 3：autograd 引擎的工作原理（`autograd.py`）

1. 每个 Value 节点存 data、grad、子节点、局部反向规则 _backward；
2. 前向运算（+,-,*,/,exp,log,tanh,relu）同时注册局部导数规则；
3. backward() 先拓扑排序，再逆序调用每个节点的 _backward，
   用链式法则把梯度累加到子节点（grad += 上游梯度 × 局部导数）。
所有框架（PyTorch/TensorFlow/JAX）都是这个思想的工程化版本。

## 自测题（答案在下方）

1. 为什么数值微分不能直接用来训练？
2. tanh 的导数为什么是 1-z²（用 z 本身表达）？
3. 前向模式 vs 反向模式的复杂度差别是什么？
4. autograd 的拓扑排序解决了什么问题？
5. "误差反向传播"中的"反向"指什么？

<details>
<summary>答案</summary>

1. 每算一个参数梯度要多次前向（前向差分 D+1 次、中心差分 2D 次），
   深度网络 D 是百万级，完全不可行；且精度受浮点舍入限制。
2. z = tanh(a)，dz/da = 1-tanh²(a) = 1-z²。前向已经算出 z，
   反向时直接用 z 就能得到导数，无需重新计算 a。
3. 设 F: R^D→R^M：前向模式 D 次遍历（每个输入方向一次），
   反向模式 M 次遍历（每个输出一次）。标量损失（M=1）→ 反向一次搞定。
4. 计算图是 DAG，反向传播要求"被依赖的节点先算完梯度"；
   拓扑排序保证这个顺序，避免重复计算或死循环。
5. 误差（损失对输出的梯度）从输出层逐层向输入层"流动"，
   与信息前向传播的方向相反 —— 即反向传播。
</details>
