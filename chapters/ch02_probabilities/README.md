## 这一章在讲什么

概率论是深度学习的数学语言。本章从**频率视角**（弯曲硬币）引入概率，
推导**和规则（边际化）**与**积规则（条件分解）**，进而得到**贝叶斯定理**；
随后覆盖连续变量的**概率密度**、**高斯分布**（含极大似然与偏差）、
**密度变换**（雅可比）、**多变量高斯**，最后是**信息论**（熵/KL/互信息）
与**贝叶斯概率**（先验→后验）。全书后续所有章节的数学骨架都在这里。

## 关键推导（中文）

### 推导 1：贝叶斯定理为什么"检测阳性≠患病"

设 C=患癌，T+=检测阳性。已知 p(C)=0.01、p(T+|¬C)=0.03、p(T-|C)=0.10。
由全概率公式：
    p(T+) = p(T+|C)p(C) + p(T+|¬C)p(¬C)
          = 0.90×0.01 + 0.03×0.99 = 0.0387
由贝叶斯定理：
    p(C|T+) = p(T+|C)p(C) / p(T+) = 0.009 / 0.0387 ≈ 0.233
直觉：10000 人里 100 人患癌（90 人检出阳性）、9900 人未患癌（297 人假阳性），
阳性共 387 人，其中真患癌 90 人 → 90/387 ≈ 23%。

### 推导 2：为什么 σ²_ML 有偏差

σ²_ML = (1/N)Σ(x_n − μ_ML)²，其中 μ_ML = (1/N)Σx_n 本身来自数据。
可以证明 E[σ²_ML] = (N−1)/N σ²_true < σ²_true。
直观：μ_ML 总是"贴着"样本，残差 (x_n − μ_ML) 比到真实 μ 的偏差小，
于是方差被系统性低估。代码用 5000 次重复实验验证了这一结论。

### 推导 3：密度变换的雅可比

若 y = f(x) 且 f 严格单调，则 p(y) = p(x)|dx/dy|。
例：x~N(0,1)，y=x²。x=±√y 两个分支，|dx/dy| = 1/(2√y)：
    p(y) = N(√y|0,1)/(2√y) + N(−√y|0,1)/(2√y) = N(√y|0,1)/√y
代码用 20 万样本直方图对比解析公式验证。

## 自测题（答案在下方）

1. 用一句话解释：为什么检测阳性的人里只有约 23% 真正患病？
2. 和规则与积规则分别对应代码里的哪个 numpy 操作？
3. σ²_ML 为什么平均低估真实方差？无偏估计应该除以多少？
4. 密度变换 y=x² 时，为什么 p(y) 在 y 接近 0 时趋于无穷？
5. 抛硬币熵在 p=0.5 时最大，这说明了什么直觉？

<details>
<summary>答案</summary>

1. 因为未患病基数（99%）远大于患病基数（1%），假阳性（3%×99%）数量
   淹没了真阳性（90%×1%）。贝叶斯定理正是把"基数"这个先验考虑进来。
2. 和规则 = `joint.sum(axis=1)`（对列求和得到边际）；
   积规则 = `pY_given_X * pX[:, None]`（条件×边际还原联合）。
3. μ_ML 是从数据估的，会"贴着"样本使残差偏小；无偏估计用除以 N-1。
4. y=x² 在 x=0 附近把无限小的 dx 压缩到 dy≈0，密度 = 概率/宽度 发散。
   这正是雅可比 |dx/dy|→∞ 的体现。
5. p=0.5 时结果最不可预测（正反等可能），信息量/不确定性最大；
   任何偏离都让结果更容易预测，熵下降。
</details>
