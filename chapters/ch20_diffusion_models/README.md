# 第 20 章：扩散模型（全书收官章）

> 第 20 章（印刷页 581-620）。脚本：`ch20_diffusion_models.py`

## 核心内容
- **前向过程**：x_t = √ᾱ_t x_0 + √(1-ᾱ_t)ε（扩散核，无需学习）
- **噪声预测网络** ε_θ(x_t, t)：训练损失 = E||ε - ε_θ||²（简化 ELBO）
- **反向采样**：从纯噪声按 DDPM 公式逐时刻去噪
- **Score 匹配**：score = -ε/√(1-ᾱ)（噪声预测 ≡ score 训练）
- **引导扩散**：classifier-free guidance（书中 20.4.2 节）

## 运行结果（可直接复现）
- 前向扩散可视化：环形 → 高斯噪声（t=0/30/60/99）
- 噪声预测损失：6.09 → 0.69
- **生成：从纯噪声重建环形分布（覆盖率 > 0.85 ✓）**

## 关键公式
- 前向：x_t = √ᾱ_t x_0 + √(1-ᾱ_t)ε
- 简化训练损失：L = E||ε - ε_θ(√ᾱ x0 + √(1-ᾱ)ε, t)||²
- DDPM 反向一步：x_{t-1} = (x_t - β_t/√(1-ᾱ_t)ε_θ)/√(1-β_t) + σ_t z
- Score：∇_x log p_t(x) = -ε_θ(x,t)/√(1-ᾱ_t)
- CFG：ε_θ(x,t,c) = ε_θ(x,t) + w·(ε_θ(x,t,c) - ε_θ(x,t))

## 自测题
1. 为什么前向过程不需要学习？
2. 训练目标为什么是预测噪声而非预测 x_0？
3. 反向采样里的随机项 σ_t z 起什么作用？
4. 扩散模型与 GAN/VAE 相比的优势？

<details><summary>答案</summary>
1. 加噪公式完全已知（高斯扩散核），只需按时间表加噪即可。
2. 预测噪声等价于预测 x_0（线性关系），且损失更简单、训练更稳定；
   噪声预测 ≡ score 匹配（20.3 节）。
3. 保证反向过程的随机性（与 x_T 的随机性一致），避免确定性退化；
   它是反向 SDE 的噪声项（20.3.4 节）。
4. 训练目标稳定（MSE，无对抗训练的不稳定性），生成质量高、
   模式覆盖好（无 mode collapse），且数学上由 ELBO/score 理论支撑。
</details>
