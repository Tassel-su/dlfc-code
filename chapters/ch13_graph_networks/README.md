## 这一章在讲什么

图（节点+边）无处不在：分子、社交网络、知识图谱。图网络的核心是
**消息传递**：每个节点聚合邻居信息更新自己的表示。本章从邻接矩阵与
置换等变出发，实现 GCN（归一化邻接矩阵上的消息传递）、半监督节点分类、
GAT（邻居注意力加权）、以及过平滑现象。

## 关键推导（中文）

### 推导 1：GCN 为什么用对称归一化 Â = D^(-1/2)(A+I)D^(-1/2)

自环 (A+I) 让节点聚合自身信息；D^(-1/2) 对称归一化避免高度数节点
（社交明星）的表示过大。传播一步：h'_i = Σ_j Â_ij h_j，
等价于"邻居的平均 + 自身"，但按度数加权，数值稳定。

### 推导 2：半监督节点分类的梯度传播

损失只定义在少数标注节点上，但反向传播经过消息传递矩阵 Â：
    dH = Âᵀ (dL/dH')
未标注节点没有直接损失，却通过 Âᵀ 收到邻居的梯度 ——
这就是"标签在图上传播"的数学机制。

### 推导 3：过平滑

行随机游走矩阵 P = D⁻¹A 的特征值 ∈ [-1,1]，P^k 当 k→∞ 收敛到
秩 1 矩阵（每行都是平稳分布）：所有节点的表示最终相同。
信息被反复混合"洗掉"，深层 GCN 因此失效。

## 自测题（答案在下方）

1. 为什么图网络必须置换等变？
2. GCN 与 CNN 的联系？
3. 为什么只需要少量标签就能分类全图？
4. GAT 与 GCN 的区别？
5. 过平滑怎么缓解？

<details>
<summary>答案</summary>

1. 图的节点编号是任意的：同一张图换个编号，函数输出必须相应置换，
   否则同一输入会有不同输出（不一致）。
2. GCN = 图上定义"卷积"：CNN 的邻域是网格，GCN 的邻域是任意图结构，
   共享权重 + 局部聚合的思想一致。
3. 消息传递让每个节点的表示融合邻居信息：标签沿边"扩散"，
   社区内的标签相互强化，少数种子即可标记全社区。
4. GCN 均匀聚合（或按度加权）；GAT 学习每个邻居的注意力权重，
   更能区分重要/不重要的邻居。
5. 浅层网络 + 残差连接 + 跳连（如 JK-Net）；或图归一化/正则化。
</details>
