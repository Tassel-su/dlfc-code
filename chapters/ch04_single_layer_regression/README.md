## 关键推导（中文）

### 推导 1：极大似然为什么等于最小二乘

噪声模型 t = y(x,w) + ε，ε~N(0,β⁻¹)。单个样本的似然：
    p(t_n|x_n,w,β) = (β/2π)^½ exp(-(β/2)(t_n - y(x_n,w))²)
全部样本的似然是乘积，取对数后：
    ln p(t|w,β) = -(β/2) Σ_n (t_n - y_n)² + 常数
最大化 ln p 等价于最小化 Σ(t_n-y_n)² —— 因为 β/2 是正常数。
所以"高斯假设下的 MLE"与"最小二乘"是同一个问题的两个说法。
代码 4.1.3 用梯度上升直接最大化对数似然，收敛到与 lstsq 相同的解。

### 推导 2：最小二乘为什么是投影

y = Φw 只可能落在 Φ 的列空间 span(Φ)（所有"可实现的预测"）。
最小二乘 = 在列空间里找离 t 最近的点 ŷ。由几何性质，残差 t-ŷ 必须
与列空间正交：Φᵀ(t-ŷ) = 0 → ΦᵀΦw = Φᵀt → w = (ΦᵀΦ)⁻¹Φᵀt。
代码 4.1.4 直接验证了正交性（2.4e-14）。

### 推导 3：偏差-方差分解

对平方损失，固定输入 x，关于数据集 D 求期望：
    E_D[(y(x;D) - h(x))²]
  = (E_D[y] - h)² + E_D[(y - E_D[y])²]      （展开平方，交叉项为零）
  = 偏差² + 方差
再加上数据本身的噪声 σ²，总期望损失 = 噪声² + 偏差² + 方差。
复杂度小 → 偏差大（拟合不足）；复杂度大 → 方差大（过拟合）。
代码 4.3 用 100 组数据集实测了这个分解。

## 自测题（答案在下方）

1. 为什么说模型 y = Σw_j φ_j(x) 是"线性的"？非线性在哪里？
2. MLE 与最小二乘等价需要什么假设？
3. 顺序学习的更新 w ← w + η(t_n-wᵀφ_n)φ_n 是怎么从误差 E_n 推导的？
4. 偏差-方差分解里，为什么复杂度太高方差会变大？
5. 多输出回归为什么可以分解为多个独立问题？

<details>
<summary>答案</summary>

1. 对参数 w 是线性的（y 是 w 的线性函数）；非线性来自基函数 φ_j(x)，
   但那是输入 x 的非线性，不影响 w 的线性结构 → 闭式解依然成立。
2. 噪声是加性高斯：t = y(x,w) + ε，ε ~ N(0, β⁻¹)。
   换个噪声分布（如拉普拉斯）MLE 就不再等于最小二乘（会变成 L1 回归）。
3. E_n = ½(t_n - wᵀφ_n)²，∇E_n = -(t_n - wᵀφ_n)φ_n，
   梯度下降 w ← w - η∇E_n = w + η(t_n - wᵀφ_n)φ_n。
4. 复杂度高 = 参数多 = 模型能记住训练数据，训练集一换预测就大不一样，
   所以预测在数据集间的波动（方差）变大；反之模型太简单则系统性偏离
   真实函数（偏差大）。
5. 因为损失对每个输出独立求和，不同输出之间没有耦合项，
   最优解 W 的第 k 列只依赖目标第 k 列 T[:,k]。
</details>
