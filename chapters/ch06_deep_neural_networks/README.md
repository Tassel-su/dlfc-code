## 这一章在讲什么

第 4-5 章是"单层"（固定基函数），本章解释**为什么需要深度**：
固定基函数受维度灾难诅咒；多层网络让基函数**从数据中学习**
（数据相关基函数），并通过层级/分布式表示获得指数级表达力。
还覆盖激活函数、万能逼近、权重空间对称性、误差函数选择，
以及应对"一对多映射"的**混合密度网络（MDN）**。

## 关键推导（中文）

### 推导 1：单隐层网络的反向传播（手动版本）

前向：a1 = W1x+b1，z = tanh(a1)，y = W2z+b2。
平方损失 E = ½(y-t)²。链式法则：
    ∂E/∂W2 = (y-t) zᵀ            ∂E/∂b2 = y-t
    δ1 = W2ᵀ(y-t) ⊙ (1-z²)        （tanh' = 1-z²）
    ∂E/∂W1 = δ1 xᵀ                ∂E/∂b1 = δ1
代码 `train_mlp` 用批量梯度下降迭代更新。第 8 章将用自动微分系统化地做这件事。

### 推导 2：为什么万能逼近成立（直觉）

单隐层网络 y = Σ_m W2_m h(w1_m x + b1_m) 是 M 个"局部特征"的加权和。
每个隐藏单元 h(w1_m x + b1_m) 可以看作一个可移动/可缩放的"基元"，
M 越大越能拼接出任意形状 —— 与傅里叶级数/多项式逼近同构。
（数学上由 Hornik 1989 等严格证明。）

### 推导 3：MDN 为什么能表达多模态

MDN 输出混合高斯参数 p(t|x) = Σ_k π_k(x) N(t|μ_k(x), σ_k²(x))，
训练时最小化负对数似然 -ln Σ_k π_k N(t_n|μ_k,σ_k²)。
对逆运动学（同一末端位置有两个关节角解），条件分布有两个峰，
单一高斯只能给出两峰的"平均"（MSE=0.10 且落在两峰之间），
MDN 的多个分量分别捕获每个峰。

## 自测题（答案在下方）

1. 为什么固定基函数在高维空间不可行？
2. 万能逼近定理保证了什么，没有保证什么？
3. ReLU 相比 sigmoid 的优势是什么？
4. "分布式表示"为什么比"局部表示"高效？
5. 什么情况下必须用 MDN 而不是普通网络？

<details>
<summary>答案</summary>

1. 网格覆盖单元数随维度指数增长（10^D），数据量永远追不上；
   且高维空间几乎处处稀疏，固定网格大部分单元是空的。
2. 保证"存在足够大的网络能逼近任意连续函数"，但没说：
   需要多少单元、如何找到这些参数（优化）、以及能否泛化。
3. ReLU 正半轴梯度恒为 1，避免 sigmoid 饱和区的梯度消失；
   但负半轴梯度为 0（死神经元问题），实践中用 Leaky ReLU 等变体。
4. 局部表示（one-hot）n 个特征只表达 n 个概念；分布式表示
   （n 个二进制特征组合）可表达 2^n 个概念，且共享子特征（泛化）。
5. 当输出 t 的条件分布是多模态的（同一 x 对应多个合理 t），
   如逆运动学、语音合成（同一文本多个音调）—— 单值网络只能给"平均"。
</details>
