## 这一章在讲什么

第 3 章系统介绍概率论中"标准分布"这座武器库：离散的**伯努利/二项/多项**、
连续的**多元高斯**（几何、条件/边际、共轭贝叶斯、MLE、顺序估计、混合）、
周期数据的 **von Mises**、统一它们的**指数族**框架，以及不假设分布的
**非参数方法**（直方图/核密度/k 近邻）。后续所有章节（回归、分类、生成模型）
都在这些分布之上构建。

## 关键推导（中文）

### 推导 1：高斯条件分布公式的直觉

联合高斯 p(x_a,x_b) 中，给定 x_b 后 x_a 的分布仍是高斯：
    均值：μ_a + Σ_ab Σ_bb⁻¹ (x_b − μ_b)   （x_b 的信息线性外推到 x_a）
    方差：Σ_aa − Σ_ab Σ_bb⁻¹ Σ_ba          （观测 x_b 减少了 x_a 的不确定性）
直觉：Σ_ab/Σ_bb 是"x_b 对 x_a 的回归系数"，条件均值就是线性回归预测。
代码 3.2.4 用"从联合分布采样 + 筛出 x_b≈1.0 的样本"验证公式。

### 推导 2：为什么高斯是自共轭的

先验 p(μ)=N(μ|μ0,σ0²)，似然 Π N(x_n|μ,σ²)。对数后验是 μ 的二次函数，
因此后验仍是高斯。配方后：
    1/σN² = 1/σ0² + N/σ²            （精度相加：数据越多信念越集中）
    μN = σN²( μ0/σ0² + N x̄/σ² )     （先验均值与数据均值的精度加权平均）
代码 3.2.6 展示先验 N(0,1) 在 5 个观测后收紧到 N(1.077, 0.091)。

### 推导 3：指数族的统一视角

指数族一般形式 p(x|η)=h(x)g(η)exp(ηᵀu(x))：
- 伯努利：η=ln(μ/(1−μ))，u(x)=x，g(η)=1/(1+e^η)
- 高斯：η=[μ/σ², −1/(2σ²)]，u(x)=[x, x²]（充分统计量是一、二阶矩）
充分统计量 u(x) 的含义：估计参数时不需要全部数据，只需要这些统计量。
代码 3.4 用 exp(ηx)/(1+exp(η)) 精确还原伯努利。

## 自测题（答案在下方）

1. 为什么 Σ_ab Σ_bb⁻¹ 被称为"x_b 对 x_a 的回归系数"？
2. 高斯共轭里"精度相加"意味着什么？
3. 顺序估计 μ_N = μ_{N-1} + (1/N)(x_N - μ_{N-1}) 中 1/N 系数的作用？
4. 为什么 m=0 时 von Mises 变成均匀分布？
5. 直方图、核密度、kNN 三种非参数估计各自的一个缺点？

<details>
<summary>答案</summary>

1. 它把 x_b 的偏差 (x_b−μ_b) 按协方差比例外推到 x_a 的均值上，
   本质与线性回归系数 Σ_ab Σ_bb⁻¹ = cov/var 相同。
2. 1/σN² = 1/σ0² + N/σ²：每个数据点贡献一份精度 1/σ²，
   数据越多后验精度越高（方差越小），对应"信息量可加"。
3. 1/N 是学习率：早期数据对均值影响大，后期单点影响小，
   保证所有数据等权（Σ 1/N = 1），从而等价于批处理均值。
4. m=0 时 exp(m cos(θ−θ0)) = 1，密度 = 1/(2π) = 均匀分布；
   所以 m 衡量"方向集中度"，m→∞ 时趋于点质量。
5. 直方图：箱宽/边界位置人为且不平滑；核密度：带宽需调，维数灾难；
   kNN：近邻数 k 需调，且密度不光滑（有断点）。
</details>
